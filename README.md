# Overview

AIM DUELS is a modern **Arena Duels 1v1** plugin for **Counter-Strike 2**. The plugin is built with a focus on high performance, stability, and ease of administration. Thanks to its well-thought-out architecture and optimized arena management system, it delivers a smooth experience for players and gives administrators full control over gameplay configuration.

# Features

## Gameplay

### Personal Weapon Selection

Players can pick their preferred weapon through the standard buy menu (<kbd>B</kbd>).

The selected weapon is automatically used in subsequent duels.

### Fast Opponent Matching

An optimized player rotation system minimizes waiting time between duels when there are enough players on the server.

### Private Duels

Players can create private duels by choosing an opponent and configuring the number of rounds.

---

## Arena Management

Arena setup is performed directly in-game.

<table>
<tr>
<td valign="top" width="50%">

- Creating new arenas
- Editing spawn points
- Teleporting to any spawn point
- Switching between arenas

</td>
<td valign="top" width="50%">

- Enabling and disabling arenas
- No plugin reload required
- No server restart required

</td>
</tr>
</table>

---

## Developer Mode

Developer mode makes map setup significantly easier.

When enabled:

<table>
<tr>
<td align="center" width="25%">Invisibility</td>
<td align="center" width="25%">Invulnerability</td>
<td align="center" width="25%">Comfortable arena editing</td>
</tr>
</table>

Every spawn point is automatically visualized with Terrorist and Counter-Terrorist agent models.

Floating labels display:

- Arena ID
- Spawn point ID

Developer mode objects are visible only to the administrator currently using it.
