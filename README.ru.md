# Возможности

## Геймплей

### Персональный выбор оружия

Игроки могут выбрать предпочитаемое оружие через стандартное меню покупки (<kbd>B</kbd>).

Выбранное оружие автоматически используется в следующих дуэлях.

### Быстрый подбор соперника

Оптимизированная система ротации игроков сводит к минимуму время ожидания между дуэлями, когда на сервере достаточно игроков.

### Приватные дуэли

Игроки могут создавать приватные дуэли, выбирая соперника и настраивая количество раундов.

---

## Управление аренами

Настройка арен выполняется прямо в игре.

<table>
<tr>
<td valign="top" width="50%">

- Создание новых арен
- Редактирование точек спавна
- Телепорт к любой точке спавна
- Переключение между аренами

</td>
<td valign="top" width="50%">

- Включение и отключение арен
- Перезагрузка плагина не требуется
- Рестарт сервера не требуется

</td>
</tr>
</table>

---

## Режим разработчика

Режим разработчика значительно упрощает настройку карты.

Когда он включён:

<table>
<tr>
<td align="center" width="25%">Невидимость</td>
<td align="center" width="25%">Неуязвимость</td>
<td align="center" width="25%">Комфортное редактирование арен</td>
</tr>
</table>

Каждая точка спавна автоматически визуализируется моделями агентов Terrorist и Counter-Terrorist.

Плавающие подписи отображают:

- ID арены
- ID точки спавна

Объекты режима разработчика видны только тому администратору, который в данный момент им пользуется.
